# food-delivery-app---UX-competitor-analysis
Competitor UX Analysis – Food Delivery Apps

📌 Project Overview

This project focuses on comparing the user experience of three popular food delivery applications: Swiggy, Zomato, and EatSure.

The analysis explores how each application handles important user interactions and identifies its strengths and possible improvements.

🔍 Areas of Comparison

1. Onboarding

- First-time user experience
- Registration and login flow
- Ease of getting started

2. Navigation

- Home screen layout
- Menu organization
- Ease of finding features

3. Checkout

- Cart experience
- Order summary
- Payment flow clarity

📊 UX Evaluation Criteria

- Ease of Use
- Navigation Clarity
- Visual Consistency
- Checkout Simplicity

🛠️ Tools Used

- Figma
- UI/UX Research
- Competitor Analysis

🎯 Project Objective

To understand different design approaches, evaluate user experiences, and identify opportunities for improving digital product usability.

📚 Key Learnings

- Understanding competitor analysis
- Identifying usability strengths and weaknesses
- Comparing user journeys
- Developing UX observation skills
